# مراجعة النطق وتوليد الصوت

## نتائج الفحص الأولي
- إجمالي السجلات: 8,043.
- الأحاديث (`hadith`): 4,000.
- القصص/المشاهد (`scene`): 4,043.
- حالة النص `plain`: 4,043 سجلًا؛ النصوص دي غالبًا من غير تشكيل كافٍ، ولذلك لا يصح اعتبار نطقها مضمونًا.
- حالة `processed`: 4,000 حديث؛ الاسم `processed` معناه أن قواعد التنظيف اتطبقت فقط، وليس شهادة بصحة كل حركة أو بصحة نص الحديث.

## التعديلات
- تثبيت الصوت `ar-SA-HamedNeural` ومعدل السرعة `+0%`.
- جعل مجلد التطبيق `a/<id>.mp3` هو وجهة التوليد؛ هذا هو المسار الذي يقرأ منه `index.html`.
- جعل سير العمل يولّد الأحاديث والقصص معًا إلى `a_staging/`.
- لا يستبدل سير العمل مكتبة `a/` القديمة إلا بعد التحقق من وجود كل ملف متوقع وأن حجمه صالح.
- إصلاح مسار استيراد `tts/clean.py` في اختبار التنظيف.
- إضافة `audit_pronunciation.py` لإنشاء تقرير وطابور مراجعة CSV.

## حدود مهمة
التشكيل الآلي لا يضمن النطق الصحيح لكل كلمة، خصوصًا أسماء الرواة والكلمات التي يتغير معناها بالحركات. طابور المراجعة في `pronunciation_review_queue.csv` يضم النصوص الموسومة `plain` أو `review`؛ يجب مراجعتها وإضافة التشكيل الصحيح من مصدر موثوق قبل الادعاء بأن كل النطق صحيح. لا تغيّر النص الأصلي للحديث بغرض تحسين الصوت.

## التشغيل
من جذر المشروع:
```bash
python test_clean.py
python tts/audit_pronunciation.py
```

لإعادة توليد المكتبة بالكامل: ارفع الملفات المعدلة إلى المستودع، ثم افتح **Actions → generate-leyh-audio → Run workflow**. يجب أن ينجح كلٌّ من التوليد والتحقق قبل نقل `a_staging/` إلى `a/`.
